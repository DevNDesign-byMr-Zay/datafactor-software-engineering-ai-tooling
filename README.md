# Datafactor Software Engineering & AI Tooling

Private assessment repository mirroring the code and configuration corpus from the Google Drive **Software Engineering & AI Tooling** collection.

## Repository policy

- Source and configuration files are preserved from the Drive corpus.
- Original engineering/domain organization is retained.
- When multiple distinct Drive files share the same filename, each is preserved with a short source-ID suffix rather than overwritten.
- Non-code presentation/document artifacts are excluded from the code assessment payload.
- Credential-bearing values are not introduced. The reviewed frontend environment file contains only localhost/training configuration and a blank token value.

This repository is staged for Datafactor code assessment and remains private until explicitly shared or made public by the owner.
